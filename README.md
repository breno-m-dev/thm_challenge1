# thm_challenge1
This was a challenge from try hack me platform. I'm making this repository to describe how I solved the challenge. The challenge consistend in finding an admin info inside a binary file.

## Tools Used

Strings.exe - to attempt to find strings inside the binary file, this is a reverse engineering tool

Python - to make a script to filter the strings made found with strings.exe, it is possible to make this filters through strings.exe. But since I already know python and it was my first time using strings .exe it made more sense to make the filter in Python to be more practical.
